How to play अन्वेषणम्

Find names of Krishna or Arjuna hidden in a Sanskrit word-search puzzle.

About the game

The Bhagavad Gita uses many names for Krishna and Arjuna. Recognizing these names can help when reading or reciting its verses.

This word-search puzzle hides names from the selected name set among Sanskrit अक्षर. Find all the names present to complete the puzzle.

Choose your puzzle

  1. Use the Krishna/Arjuna checkbox to choose whose names you want to find.
  2. Select a difficulty: सरलम् for 5×5, मध्यमम् for 7×7, or कठिनम् for 10×10.
  3. Read the number of names present above the grid. The exact number can vary between randomly generated puzzles.

Changing the name set or difficulty generates a new puzzle. Use पुनः to generate another puzzle with the current settings.

Find a name

  1. Look for a complete name running horizontally to the right, vertically down, or diagonally down-right.
  2. Click or tap the first अक्षर of that name.
  3. The game highlights the complete matching name and updates the found count.
  4. Continue until all names present have been found.
Clicking an अक्षर in the middle of a name does not select that name. You do not need to drag across its letters.

Example

For कुरुनन्दन, click the starting कु.

On a computer, hover over an अक्षर to view its Roman transliteration.

Use help

Control What it shows
नामपदानि कानि? Lists all names from the selected Krishna or Arjuna set. Some of these names may not be present in this puzzle.
More Help!! Lists the same names and makes those present in the current puzzle bold.

The help text appears above the grid. Use the names to identify their starting अक्षर in the puzzle.

Play on paper

You can print the game page using your browser’s Print command. On a computer, press Ctrl + P or Command + P.

Find and mark the names on paper. The on-screen found count updates only when you select answers in the game.

Custom puzzle sizes

The game accepts grid sizes from 4 to 15 through its size URL parameter.

For example, ../index.html?size=7&m=a opens a 7×7 puzzle using Arjuna’s names.

  • m=a selects Arjuna.
  • m=s selects Krishna.
  • size=7 selects a 7×7 grid.

For ordinary play, use the three difficulty controls provided on the game page.

Current limitations

Random puzzles cannot be reproduced by URL

Refreshing the page generates another random puzzle. The URL preserves the name set and size, but it does not identify the exact letter arrangement.

Help lists names rather than complete paths

More Help identifies names present in the puzzle. It does not draw all their locations on the board.
