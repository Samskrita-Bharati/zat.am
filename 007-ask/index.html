How to play

Press Start to reveal the grid and begin the countdown. Find a name and click or tap its first अक्षर. The whole name will be highlighted.

Names run horizontally to the right, vertically down, or diagonally down-right. Clicking a letter in the middle does not select the name.

Use the checkbox to switch between Krishna and Arjuna. Select a difficulty to generate a new puzzle.

The first help option lists all names in the selected set and unlocks More Help. More Help makes names present in this puzzle bold. Each help option is charged once per puzzle, even if opened again.

On a computer, hover over an अक्षर to see its transliteration.
