# Sanskrit Animal Nickname Generator

`006-nk` is a small random name generator, not a real game. Click **नाम किम्?** to
generate a nickname using a random English adjective and a Sanskrit animal
name.

## Files

- `index.html` contains the generator logic and page markup.
- `words.json` contains the English adjective and Sanskrit animal name lists.
- `style.css` contains responsive styling specific to the generated-name card.
- `../shared/game-theme.css` supplies the shared page shell, heading, play area,
  and button styling.
- `../js/navbar-loader.js` loads the shared site navigation.

## Responsive layout

The page uses the shared responsive game shell and button styles. Its generated
name uses a fluid font size and spacing, and the button fills the available card
width on small screens.
